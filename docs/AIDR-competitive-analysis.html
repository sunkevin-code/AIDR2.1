三、专项增强优化建议

3.1 身份图谱技术 (Identity Graph)

当前 AIDR 只有 Agent → Session → Policy 的三层关系。缺少身份、资源、行为之间的关联映射。

Agent ──→ Session ──→ Policy

业界最佳 (Cisco AI Defense)

3.2 意图识别与行为偏移技术

当前 analyzePrompt() 使用正则匹配意图（WRITE_INTENT / SHELL_INTENT / NETWORK_INTENT）。业界最佳实践是使用 ML 模型进行多标签意图分类。

🧠 建议新增: lib/engine/intentClassifier.js 替换 sessionPolicyEngine.js 中的正则意图检测 → 38维特征 → 6 标签多分类 ONNX 模型
class IntentClassifier {
  constructor(modelPath) {
    this.model = loadONNX(modelPath);
    this.labels = [
      "file_read", "file_write", "shell",
      "network", "mcp_use", "data_exfil"
    ];
  }

  classify(prompt) {
    const features = extractFeatures(prompt);  // 38维
    const probs = this.model.predict(features);
    return {
      intents: this.labels.map((l,i) => ({
        label: l, probability: probs[i]
      })),
      primary: this.labels[argmax(probs)]
    };
  }
}

行为偏移增强：4 维 → 8 维

当前 4 维（硬编码权重）增强 8 维（动态自适应权重）
目标一致性✅ 目标一致性
能力增量✅ 能力增量
行为顺序✅ 行为顺序
数据边界✅ 数据边界
—🆕 身份信任度 (identity_trust)
—🆕 工具调用频率 (tool_frequency)

增强版 EnhancedDriftEngine 使用 EWMA（指数加权移动平均）持续更新基线，维度权重根据历史方差动态调整——方差大的维度权重降低，减少噪声干扰。

3.3 行为图谱技术

当前 sessionContextGraph.js 已实现 5 种节点（context/intent/policy/tool/decision）+6 种关系。缺乏跨会话聚合和社区发现。

🔗 建议增强: lib/engine/behaviorGraph.js → EnhancedBehaviorGraph 新增三种能力：跨会话聚合 · 社区发现 · 图异常检测

跨会话行为链

聚合同一 Agent 24h 内所有会话，构建统一行为图，发现跨会话的攻击链模式。

社区发现

使用 Louvain 算法识别工具使用模式群组，发现异常分组。

图异常检测

基于 Graph Edit Distance + Isolation Forest，比较当前会话图与基线图的差异。

因果推断

Granger 因果性 + 最短因果路径，判断事件 A 是否导致事件 B。

Web 控制台集成：使用 Cytoscape.js 替代现有 SVG 图谱，支持交互式拖拽、社区高亮、节点检索。
