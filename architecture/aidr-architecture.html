AIDR：AI Agent 零信任最小权限控制防御系统

面向每个会话、每个任务、每个工具调用动态生成最小权限策略，并在主机/容器/工具网关执行点进行实时放行、阻断、降权和告警。 参考思路包括 Cisco AI Defense 的 AI 工作流防护、Cisco Hypershield/Tetragon 的 eBPF 可观测与执行、以及 Secure Workload 的策略发现和微分段。

策略学习与推理 最小权限策略 实时执行与阻断 审计与告警 MCP/工具网关

1. 会话与任务理解层

Plan Before Permit

所有 AI Agent 任务先进入意图分析和行为链建模，生成可解释的任务画像。

Agent 会话代理

采集用户请求、系统提示词、工具清单、MCP manifest、工作区边界、当前身份和环境上下文。

  • 会话 ID、任务 ID、模型/插件/连接器
  • 敏感目录、密钥、网络域名、数据库和 API

意图与行为链分析器

把自然语言任务转换成可执行行为图，预测文件、进程、网络、MCP、接口和权限需求。

  • 任务目标：读、写、构建、测试、部署、外发
  • 行为链：读取上下文 -> 调用工具 -> 生成变更 -> 验证

工具/MCP 风险画像

对 MCP server、浏览器、shell、代码解释器、数据库、云 API 等能力打标签，识别高风险动词。

  • 危险能力：删除、移动、外传、安装、凭据访问
  • 信任等级：本地只读、工作区写、互联网、特权系统

攻击面检测

检测 prompt injection、越权工具诱导、路径穿越、敏感数据外传、横向移动和供应链拉取。

2. 动态策略自学习与决策层

Least Privilege per Task

系统根据任务画像生成一次性、短时效、可回滚的策略，并从真实遥测持续收敛。

策略生成器

生成任务级 Allow/Deny/Ask 策略，包含主体、资源、动作、条件、有效期和证据链。

  • 允许：只读指定文件、写入工作区目标路径、访问必要 MCP
  • 拒绝：读取密钥目录、访问无关 repo、未知外网域名、提权

策略自学习引擎

对比计划行为与真实行为，学习正常基线，自动收窄过宽权限并标记异常偏离。

  • 策略推荐：从历史成功任务归纳路径和接口集合
  • 漂移检测：行为链偏离、工具突增、敏感资源触碰

风险评分与审批

为每个动作计算上下文风险，低风险自动放行，高风险触发用户确认或安全团队审批。

  • 风险因素：敏感资源、不可逆写入、网络外发、未知工具
  • 响应：放行、阻断、只读降级、沙箱执行、人工确认

策略包

输出给执行点的机器可读策略：文件 ACL、进程树规则、网络 egress、MCP allowlist、命令约束。

任务级闭环

采集会话、工具、工作区、身份上下文
理解意图、资源、行为链、风险点
生成最小权限策略和有效期
执行主机/MCP/网络实时拦截
审计事件、证据、策略命中原因
学习基线收敛、策略推荐、异常回放

3. 实时执行与运营层

Runtime Enforcement

在主机、容器、网络、MCP 网关和工具代理上执行策略，形成统一审计视图。

eBPF / LSM 执行点

Linux 生产版执行文件、进程、网络、capability、syscall 级拦截；可对接 Tetragon/Falco/Cilium。

  • 文件：open/read/write/unlink/rename
  • 网络：connect/dns/http egress
  • 进程：execve、子进程树、提权行为

Windows 执行点

Windows MVP 使用 ETW/WMI/FileSystemWatcher/防火墙/进程终止实现监控与准实时阻断；生产版可接 WFP、minifilter 或商业 EDR。

MCP / Tool Gateway

所有工具调用先经过网关，检查 task_id、工具名、参数、目标资源和输出数据分类。

运营控制台

展示实时事件、策略差异、阻断原因、攻击链回放、例外审批和合规报表。

核心策略对象

对象示例
主体agent:codex, session:s-20260528, task:t-build-demo
资源C:\Users\...\AIDR\demo\**, MCP:browser, api:github.com
动作read, write, exec, connect, tool.invoke
条件task_id 匹配、TTL 30 分钟、输出不含 secret 分类
响应allow, deny, ask, alert, degrade_to_readonly, sandbox

攻击防御示例

攻击行为AIDR 响应
Prompt injection 要求读取 .env 并上传策略无密钥读取和未知域名外发权限，实时阻断并告警
Agent 试图删除工作区外目录文件执行点拒绝 unlink/rename，生成高危事件
未知 MCP 工具请求数据库凭据MCP Gateway 拦截，要求人工审批或隔离
任务行为链突然调用 shell 下载脚本漂移检测升高风险，降级为只读沙箱
